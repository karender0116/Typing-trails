# Typing Trails 🌈⌨️

Colorful elementary typing and computer-skills learning site.

## Current prototype
- Student classroom-code/username login UI
- Teacher dashboard prototype
- Mouse Mission
- Home Row Heroes
- Keyboard basics
- Space & Enter
- Beginner typing practice
- Stars and badges

## Planned online version
Supabase will provide persistent multi-class, multi-computer student progress. Students will authenticate with classroom code + username + PIN and will not need email addresses.
